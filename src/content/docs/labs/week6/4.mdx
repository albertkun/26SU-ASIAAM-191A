On GitHub you may have seen this nagging icon a few times by now:

<img src="/26SU-ASIAAM-191A/labs/week6/media/pullRequest.png" alt="GitHub banner prompting you to compare and pull request a recently pushed branch" />

You will then be greeted by a new page where you can title, assign, comment, etc. about the pull request (or PR):

<img src="/26SU-ASIAAM-191A/labs/week6/media/PRcreate.png" alt="The GitHub Open a pull request page with title, description, and reviewer fields" />

And most importantly create a `pull request`:

<img src="/26SU-ASIAAM-191A/labs/week6/media/testPr.png" alt="The Create pull request button on GitHub" />

After clicking the button to `create a new pull request` scroll down to the resulting page:

<img src="/26SU-ASIAAM-191A/labs/week6/media/testPR_2.png" alt="The newly opened pull request page on GitHub" />

You should be able to click on `merge` if your `pull request` has no `merge conflicts`:

<img src="/26SU-ASIAAM-191A/labs/week6/media/testPR_3.png" alt="The Merge pull request button available because there are no conflicts" />

Click to `confirm` the auto merge:

<img src="/26SU-ASIAAM-191A/labs/week6/media/testPR_4.png" alt="The Confirm merge button on GitHub" />

And now you can delete the branch:

<img src="/26SU-ASIAAM-191A/labs/week6/media/testPR_5.png" alt="The Delete branch button shown after a pull request is merged" />

## Warning: Merge Conflicts do not allow you to auto-merge a Pull Request!

:::danger[Warning! Merge Conflicts prevent auto-merges of a Pull Request!]
You will be unable to `auto-merge` if there is a merge conflict, so refer to the `merge-conflict` steps in order to finish the `pull request`.
:::
